Adaptive Bitrate (ABR) Algorithms

Hybrid QoE Active
Throughput-Based Select

Throughput-Based ABR

Direct bandwidth matching using harmonic mean of recent segment throughputs with safety headroom.

Rk ≤ 0.85 × HarmonicMean(Tpast 5)
  • Window: 5 chunks
  • Safety Factor: 0.85
  • Property: Reactive to capacity changes
Buffer-Based (BBA) Select

Buffer-Based ABR (BBA)

Adapts bitrate directly from client playback buffer occupancy, completely ignoring throughput spikes.

f(B) ∈ [Reservoir: 5s, Cushion: 10s, Max: 15s]
  • Reservoir: 5.0s (min 360p)
  • Cushion: 10.0s (linear scaling)
  • Hysteresis: 0.5s stability band
Custom Hybrid ABR Active

QoE-Driven Hybrid ABR

Optimizes QoE by combining volatility-discounted throughput, buffer drain feasibility, and switching penalties.

max [ q(R) − β · StallRisk − λ · |ΔR| ]
  • Throughput: Volatility (CV) discount
  • Buffer: Cushion scale + Drain check
  • Switching: Penalty λ = 0.5
